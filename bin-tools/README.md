## Bibliography tools for AI-generated entries

Entries produced by an AI agent live in `ai_slop/` and carry a
`comment = {generated_by_...}` tag. They are candidates: none of them should
reach a curated file (`floss*.bib` in the repository root) until its metadata
has been checked against Crossref and OpenAlex. Four scripts support that flow.
All of them follow the conventions of `fix-bib.py`: bibtexparser v2, Rich output,
a read-only dry run by default, `--apply` to write, a `.bak` backup unless
`--no-backup`, and `--check`/`--json`/`--gha` for CI.

```
ai_slop/*.bib --dedup-bib--> --verify-bib--> --promote-bib stamp--> --promote-bib promote--> floss*.bib
                                                                                                  |
                                                                          CI: promote-bib check --+
```

Install the dependencies with `pip install -r bin-tools/requirements.txt`.
`promote-bib.py` imports `dedup-bib.py`, so keep the two in the same folder.

### dedup-bib.py: remove duplicate entries

Finds duplicates by key, by DOI/arXiv id, and by title + year + compatible authors,
merges each group into the most complete entry (filling missing fields, joining
`comment` tags), and edits the file as text so untouched entries stay identical.

```
python bin-tools/dedup-bib.py ai_slop/ft50_open_source.bib            # dry run
python bin-tools/dedup-bib.py ai_slop/ft50_open_source.bib --apply
python bin-tools/dedup-bib.py floss*.bib --across-files --report dups.md   # report only
python bin-tools/dedup-bib.py floss.bib --check                        # CI: exit 2 if duplicates
```

Other options: `-o FILE`, `--keep best|first`, `--title-threshold`, `--key-map FILE.tsv`, `--json`, `--gha`, `-r`.

### verify-bib.py: check entries against Crossref and OpenAlex

Compares title, authors and abstract with the registry record (DOI lookup first,
title search as a fallback). Each entry gets a status: `VERIFIED`, `WARN`,
`MISMATCH`, `NOT_FOUND` or `UNCHECKED`. Abstracts marked `[Paraphrase]` are not compared.
Answers are cached in `~/.cache/verify-bib/cache.json`.

```
export OPENALEX_API_KEY=...          # free key, required by OpenAlex since Feb 2026
export CROSSREF_MAILTO=you@example.org
python bin-tools/verify-bib.py ai_slop/ft50_open_source.bib --json > verify.json
python bin-tools/verify-bib.py ai_slop/ --recursive --problems-only --report verify.md
```

Other options: `--source crossref|openalex|both`, `--only KEY...`, `--tag TAG...`,
`--limit N`, `--no-search`, `--refresh`, `--no-cache`, `--check`, `--strict`, `--gha`.
Without the OpenAlex key, use `--source crossref`.

### promote-bib.py: stamp, check, promote

`stamp` adds a field to every AI-generated entry that `verify-bib` marked `VERIFIED`:

```
verified = {crossref+openalex; 2026-11-20; fp=3fa91c07d2}
```

The three parts are the registries that found the work, the date, and a fingerprint
of the entry's title, author surnames, year and DOI. Editing an abstract, note or
venue keeps the stamp valid; changing any fingerprinted field makes it `STALE`.
Hand-written entries are not stamped unless you pass `--all`.

```
python bin-tools/promote-bib.py stamp ai_slop/ft50_open_source.bib --report verify.json --apply
python bin-tools/promote-bib.py stamp ai_slop/ft50_open_source.bib --verify --apply   # verify and stamp in one go
python bin-tools/promote-bib.py promote ai_slop/ft50_open_source.bib --to floss-sna.bib            # dry run
python bin-tools/promote-bib.py promote ai_slop/ft50_open_source.bib --to floss-sna.bib --apply
python bin-tools/promote-bib.py check floss*.bib                       # the gate
```

* `stamp` options: `--allow-warn` (also stamp `WARN`), `--restamp`, `--all`, `--date`, `--ai-tag REGEX`.
* `promote` moves only validly stamped entries, skips works already in the target,
  reports key collisions instead of overwriting, and leaves unstamped entries behind.
  Add `--copy` to keep them in the source too.
* `check` exits 2 when an AI-generated entry is `UNSTAMPED`, `STALE` or `MALFORMED`.
  Options: `--json`, `--report FILE.md`, `--gha`.

An entry counts as AI-generated when a `comment` tag matches `^generated_by_` or its
`note` contains "Generated by".

### CI: Verification gate

`.github/workflows/verification-gate.yml` runs on pushes and pull requests that touch
a root `*.bib` file or these scripts. It runs the offline tests in `acceptance_tests/`
and then `promote-bib.py check ./*.bib`. The `ai_slop/` folder is deliberately not
checked, because its entries are unstamped until promoted. The workflow makes no
network calls: verification happens on your machine, and CI only confirms that the stamps are present and still match.

To make the gate blocking, require the `gate` check in the branch protection rules for `main`.

### Tests

```
python -m pytest -q acceptance_tests
```

The suites use a fake transport, so they need no network or API keys. The live
`--verify` and `verify-bib` paths have not yet been exercised against the real APIs.
